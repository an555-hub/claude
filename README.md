# CHAJIKAN — お茶の福利厚生サービス

企業向けの「お茶の福利厚生サービス」を紹介する1ページ構成のマーケティングサイトです。
全国の茶産地から仕入れた茶葉を専用のティースタンドとともにオフィスへ届ける、
架空のサブスクリプション型サービス「CHAJIKAN」を題材にしています。

## 構成

```
.
├── index.html          # ページ本体（1ページ構成）
├── assets/
│   ├── css/style.css   # スタイル一式
│   ├── js/main.js      # UI挙動（ナビ、FAQ、料金トグル、フォーム等）
│   └── img/            # 画像用ディレクトリ（現状アイコンはSVG/CSSで表現）
└── README.md
```

## セクション

- ヒーロー（キャッチコピー・導入企業数などの実績数値）
- 課題提起（オフィスの休憩・福利厚生に関する課題）
- サービスの特徴（6つの特徴）
- 導入メリット（従業員向け／企業向け）
- 料金プラン（ライト／スタンダード／プレミアム、月払い・年払い切替）
- 導入の流れ（4ステップ）
- 導入企業の声（架空の事例）
- よくある質問（アコーディオン）
- お問い合わせフォーム（フロントエンドのみのデモ実装）

## 動作確認方法

静的サイトのため、`index.html` をブラウザで直接開くか、簡易サーバーで確認できます。

```bash
python3 -m http.server 8000
# http://localhost:8000 にアクセス
```

## 補足

- お問い合わせフォームはフロントエンドのみのデモ実装です。実運用時はバックエンドAPIとの連携が必要です。
- 掲載している企業名・導入事例・数値はすべて説明用のサンプルであり、実在の企業とは関係ありません。
